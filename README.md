## Exploratory Data Analysis (EDA)

The EDA process for this project is documented in [notebook/eda.ipynb](notebook/eda.ipynb). The main steps include:

- **Data Loading & Cleaning:**  
  The dataset is loaded from CSV, unnecessary columns are removed, and missing values are visualized and handled.

- **Text Preprocessing:**  
  Headlines are tokenized, lowercased, and stopwords are removed using NLTK.

- **Descriptive Statistics:**  
  The notebook provides summary statistics for the dataset, including the number of articles per publisher and headline length distribution.

-
- **Example Output:**  
  The notebook prints processed DataFrame samples, keyword lists.

For details and code, see [notebook/eda.ipynb](notebook/eda.ipynb).
